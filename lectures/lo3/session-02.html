HTML forms

An HTML form is used to collect user input. The input is most often sent to a server for processing. You use forms every day: logging in, signing up, searching, contacting a company, paying at a checkout.

The <form> element creates a form. Everything the user types or picks goes inside it.

<form action="/register" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
  <input type="submit" value="Send">
</form>

Form attributes

Attributes on the <form> tag say where and how the data is sent.

AttributeWhat it doesExample
actionThe address (URL) that receives the dataaction="/register"
methodHow the data is sent: get or postmethod="post"
nameGives the form a namename="signup"
targetWhere the answer opens: _self (same tab) or _blank (new tab)target="_blank"
autocompleteLets the browser suggest saved values (on or off)autocomplete="off"
enctypeHow the data is packed. Use multipart/form-data with post when the form uploads filesenctype="multipart/form-data"
novalidateSwitches off the browser's built-in checkingnovalidate

GET or POST?

GET

Puts the data in the web address, like ?name=Nimal. Anyone can see it, and the page can be bookmarked.

Use for: searches and filters.

POST

Sends the data inside the request, so it is not shown in the address. It can carry much more data.

Use for: passwords, sign-ups, anything that changes something.

A form only collects data

Something on a server (or JavaScript in the page) has to process what is sent. In this session we focus on building forms that look right and check the user's input. In the practice editors below, pressing Submit shows a message instead of sending anything.

HTML form elements

A <form> can contain one or more of these form elements:

ElementWhat it is for
<input>A field the user fills in. It looks different depending on its type
<label>A caption for a field
<select>A drop-down list
<option>One choice inside a drop-down list
<optgroup>Groups options inside a drop-down list
<textarea>A multi-line text field
<button>A clickable button
<fieldset>Groups related fields in a box
<legend>A caption for a fieldset
<datalist>A list of suggestions for an input
<output>Shows the result of a calculation

The <input> element

The <input> element is the most used form element. It can be displayed in many ways, depending on its type attribute. The four you will meet first:

  • type="text" displays a single-line text field
  • type="radio" displays a radio button (choose one of many)
  • type="checkbox" displays a checkbox (choose zero or more of many)
  • type="submit" displays a button that submits the form
Try it

Click an input type to see how it looks and what the code is.

Always give an input a name

The name attribute labels the data when it is sent (for example email=nimal@example.com). An input without a name is not sent at all. Radio buttons that belong together must share the same name, and that is what makes them "one choice only".

The <label> element

The <label> element defines a label for a form element. The for attribute of the label must be equal to the id of the input, to bind them together.

<label for="email">Email:</label>
<input type="email" id="email" name="email">

Bigger click area

Clicking the label selects the input. Great for small radio buttons and checkboxes.

Accessible

Screen readers read the label out when the field is selected, so people who cannot see the screen know what to type.

Clear for everyone

A visible caption tells every user what each field is for.

<select>, <textarea> and <button>

The <select> element

The <select> element defines a drop-down list. Inside it you put <option> elements. Each <option> defines one choice the user can select.

<label for="city">City:</label>
<select id="city" name="city">
  <option value="colombo">Colombo</option>
  <option value="galle">Galle</option>
</select>

The <textarea> element

The <textarea> element defines a multi-line input field. Its size is set with rows (visible lines) and cols (visible width in characters).

Try it

The <button> element

The <button> element defines a clickable button. Its type decides what it does:

  • type="submit" sends the form (this is the default inside a form)
  • type="reset" clears the form back to its starting values
  • type="button" does nothing by itself, so you can attach your own action
<button type="button" onclick="alert('Hello!')">Say Hello</button>
What is onclick?

It tells the browser to run a little JavaScript when the button is clicked. alert('Hello!') pops up a message box. You will learn JavaScript properly later; for now you can copy this pattern.

HTML input attributes

Attributes make inputs smarter. They can give hints, set limits, and stop users sending bad data. The browser checks many of them for you before the form is submitted. This is called form validation.

AttributeWhat it does
nameThe name of the data. No name, nothing sent
valueThe starting value (or the value that is sent for radios and checkboxes)
placeholderGrey hint text shown while the field is empty
requiredThe field must be filled in before the form can be submitted
readonlyThe user can see the value but cannot change it. It is sent
disabledThe field is greyed out and unusable. It is not sent
min / max / stepThe smallest and largest value (and the step) for numbers, dates and ranges
maxlengthThe most characters that can be typed
patternA rule the text must match, for example [0-9]{10} for exactly 10 digits
autofocusThe field is selected as soon as the page loads
checked / selectedA radio, checkbox or option that starts chosen

Summary

  • A form collects user input. The <form> element holds it, with action and method saying where and how it is sent.
  • The <input> element changes with its type: text, email, password, number, date, file, radio, checkbox, color, range, submit, reset.
  • A <label> is linked to an input by matching for and id.
  • Use <select> for drop-down lists, <textarea> for long text and <button> for actions.
  • Give every input a name. Use attributes like required, min, max, maxlength and pattern to check input.
