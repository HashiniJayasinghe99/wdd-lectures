What is web design?

Web design is the visual appearance and the layout of a website. It decides what visitors see and how easy the site is to use.

▦

Layout

Where the menu, headings, text and images sit on each page.

🎨

Colour and type

The colours and fonts that give the site its look and make it easy to read.

📷

Images and brand

Photos, icons and a logo that match the organisation's brand.

Good design is for everyone

A well designed site follows accessibility and inclusivity guidelines (for example the W3C guidelines and the Equality Act 2010), so people with different needs can use it. You will plan for this in your assignment.

Wireframes: the blueprint of user experience

Before we start building, we plan. A wireframe is a low-fidelity visual representation of a website's layout. It is like the architect's blueprint of a building: it focuses on structure, content and functionality rather than visual design.

Structure

How the elements are organised on the page.

Content

What information will be displayed.

Functionality

How users will interact with the interface.

A low-fidelity wireframe: boxes and labels only, no colours or real images.

Why are wireframes so useful?

Clear communication

A common language for clients, designers and developers, so everyone agrees before detailed design starts.

Early feedback

Quick and cheap to change, so usability problems are found early.

Faster development

Structure and functionality are decided up front, so there are fewer costly changes later.

The art of wireframe design

  1. Understand user needsLook at user research, personas and user flows to find the main goals of your audience.
  2. Sketch and ideateStart with rough sketches on paper. Do not worry about perfection yet.
  3. Define content and hierarchyDecide what content each screen needs and what matters most. Use placeholder text and images.
  4. Layout and interactivityArrange the elements, think about navigation, and map out buttons, forms and other interactions.

HTML basics

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages. It describes the structure of a page using a series of elements. Elements tell the browser how to display the content and label each piece of it, such as "this is a heading", "this is a paragraph" or "this is a link".

What is an HTML element?

An element is defined by a start tag, some content and an end tag. The element is everything from the start tag to the end tag.

What is an HTML attribute?

Attributes give extra information about an element. They are always written in the start tag and usually come as a name and value pair: name="value".

<a href="https://example.com">Visit my site</a>
Start and end tags Attribute name Attribute value Content

Basic HTML structure

<!DOCTYPE html>
<html>
<head>
  <title>Web Design & Development</title>
</head>
<body>
  <h1>My First Web Page</h1>
</body>
</html>
PartWhat it does
<!DOCTYPE html>Declares that this document is an HTML5 document
<html>The root element of an HTML page
<head>Contains information about the page (meta information)
<title>The page title, shown in the browser tab or title bar
<body>The container for everything visible on the page
Good practice for real projects

Professional pages usually add three more things. They are not needed for the practice below, but use them in your assignment:

<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Web Design & Development</title>
</head>

lang helps screen readers pronounce the page correctly, charset shows all characters correctly, and viewport makes the page work on phones.

HTML headings

Headings are defined with the <h1> to <h6> tags. <h1> is the most important heading and <h6> the least important.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>

Tip: use one <h1> per page, and choose a heading by its importance, not by how big it looks. (You can change the size later with CSS.)

HTML paragraphs

The <p> element defines a paragraph. A paragraph always starts on a new line, and the browser automatically adds some white space (a margin) before and after it.

<p>This is a paragraph.</p>
Activity 3Do it yourself+10 points

HTML links

Links are hyperlinks. A user can click a link to jump to another page or site. When you move the mouse over a link, the arrow turns into a little hand.

<a href="https://www.wikipedia.org">Visit Wikipedia</a>

Tip: write link text that makes sense on its own ("Visit Wikipedia", not "click here"). It helps everyone, especially people using screen readers.

Activity 4Do it yourself+10 points

HTML images

The <img> tag embeds an image in a page. Images are not really inserted into the page; they are linked, and the tag creates a holding space for the picture it points to.

The <img> tag is empty: it has attributes only and no closing tag. It has two required attributes:

  • src specifies the path to the image
  • alt specifies alternative text, used by screen readers and shown if the image cannot load
<img src="photo.jpg" alt="A student at a laptop" width="300">
Try it in VS Code

Create a folder called image-practice, put any image inside it (for example student.jpg), move myWebPage.html into the same folder, and use that file name as the src.

HTML lists

Lists group a set of related items. There are two types:

Unordered list

Starts with <ul>. Each item starts with <li>. Items get bullets by default.

<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>

Ordered list

Starts with <ol>. Each item starts with <li>. Items get numbers by default.

<ol>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ol>

HTML tables

A table is made of cells inside rows and columns. Each row starts with <tr> and ends with </tr>. Each normal cell is a <td>, and a header cell is a <th>.

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Emil</td>
    <td>27</td>
  </tr>
</table>
All the table tags
TagPurpose
<table>Defines a table
<th>Defines a header cell
<tr>Defines a row
<td>Defines a cell
<caption>Defines a table caption
<colgroup>Groups one or more columns for formatting
<col>Sets properties for each column inside a colgroup
<thead>Groups the header content
<tbody>Groups the body content
<tfoot>Groups the footer content

Tip: use tables for data (like a timetable), not for page layout.

The HTML div element

The <div> element is a container for other HTML elements. By default it is a block element: it takes all the available width and starts on a new line. It becomes much more useful once you learn CSS, because you can style and arrange whole groups of elements at once.

<div>
  <h2>A box</h2>
  <p>Everything between the div tags belongs to this box.</p>
</div>
