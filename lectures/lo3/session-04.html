What is CSS?

CSS stands for Cascading Style Sheets. It is the language we use to style an HTML document. It describes how HTML elements should be displayed, bringing your web pages to life with colours, layouts and visual effects.

Remember from Session 01: HTML is the structure, CSS is the style, and JavaScript is the behaviour. CSS never changes what is on the page, only how it looks.

Why "cascading"?

Many rules can apply to the same element. CSS has a clear order for deciding which rule wins, so the styles "cascade" down like a waterfall. You will see the details when we look at selectors.

Understanding the core: CSS syntax

Every CSS rule consists of a selector and a declaration block.

  • The selector points to the HTML element you want to style.
  • The declaration block (inside curly braces) contains one or more declarations, separated by semicolons.
p { color: blue; font-size: 12px; }
Selector Property Value

Properties and values

A declaration includes a CSS property name, a colon, and a property value. Properties are the aspects you want to change (for example color, font-size). Values say how they should look (for example blue, 16px).

The CSS box model

Every HTML element is treated as a rectangular box, made of four layers:

  • Content: the actual text or image inside the box.
  • Padding: clears an area around the content, inside the border.
  • Border: a line that goes around the padding and content.
  • Margin: clears an area outside the border, creating space between elements.

Positioning elements: relative vs. absolute

Relative positioning

The element is positioned relative to its normal position. The offsets (top, bottom, left, right) move it away from where it would normally be. The space it used to fill stays reserved.

Absolute positioning

The element is positioned relative to its nearest positioned ancestor (instead of the page). It is removed from the normal flow, so other elements ignore it. This allows precise placement.

.box-2 { position: relative; top: 20px; left: 30px; }
.box-4 { position: absolute; top: 0; right: 0; }

Three ways to apply CSS to your HTML

Inline styles

Applied directly to one element with the style attribute. Best for unique, one-off styling, but can make code hard to manage.

Internal styles

Written inside <style> tags in the <head> of one HTML document. Ideal for single-page styles.

External stylesheet

Written in a separate .css file and linked to the HTML. The most common and recommended way for large websites.

When rules clash

If two rules style the same thing differently, an inline style beats the others. Between an internal and an external stylesheet, the one that comes later in the page wins.

Powerful CSS selectors for precise styling

Selectors are patterns used to select the HTML elements you want to style. Mastering them is key to efficient and effective CSS.

Element selector

Targets all instances of an HTML element, such as p for paragraphs or h1 for main headings.

p { color: navy; }

Class selector

Targets elements with a specific class attribute. Identified by a dot (.) followed by the class name. Many elements can share a class.

.note { color: green; } → <p class="note">

ID selector

Targets a single, unique element with a specific id attribute. Identified by a hash (#) followed by the ID name. Use each id only once per page.

#unique-id { color: red; } → <p id="unique-id">

Grouping selector

Applies the same style to several selectors by separating them with commas.

h1, h2, p { font-family: Arial; }

Best practices: clean and maintainable CSS

Organise your code

Use comments, consistent naming conventions and modular CSS for better readability and maintainability.

Prioritise specificity

Understand how different selectors override each other, to avoid unexpected styling issues.

Validate your CSS

Use a CSS validator (such as the W3C CSS Validator) to catch errors and check cross-browser compatibility.

Summary

  • CSS (Cascading Style Sheets) styles HTML. A rule is a selector plus a declaration block of property: value; pairs.
  • Every element is a box: content, padding, border, margin.
  • position: relative moves an element from its normal place. position: absolute places it from the nearest positioned ancestor.
  • CSS can be inline, internal or external. External stylesheets are best for real websites.
  • Selectors: element, .class, #id and grouping, selectors.
  • Keep CSS clean: comment it, understand specificity and validate it.
